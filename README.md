# Rock-Paper-Scissors Simulator

のび太とスネ夫がジャンケンを行い、それぞれの勝率を集計するPythonプログラムです。

## 仕様

- のび太（`N`）はグー・チョキ・パーを均等な確率で選びます。
- スネ夫（`S`）は、自分が過去に出した各手の勝率を比較し、最も勝率が高い手を選びます。同率の手が複数あれば、その中からランダムに選びます。
- まだ出していない手の勝率は0%として扱います。そのため、初戦は3手からランダムに選びます。
- アイコも1回として総勝負数に含めますが、どちらの勝ちにも数えません。

## 必要環境

- Python 3.10以上
- 外部ライブラリなし

## 実行方法

リポジトリのルートで次を実行します。

```shell
python main.py 10000
```

実行例（結果は実行ごとに変わります）:

```text
N: 33.16%
S: 33.52%
```

再現可能な結果が必要な場合は、任意の乱数シードを指定できます。

```shell
python main.py 10000 --seed 42
```

勝負回数には1以上の整数を指定してください。

## 均等性テスト

のび太が1万回選んだ3種類の手が、すべて理論値33.33%から±1パーセントポイント以内であることを確認します。テストが失敗した場合は終了コード1を返します。

```shell
python test.py
```

出力形式は「グーの出現率 判定結果」です。

```text
32.47% True
```

すべてのルールと戦略の単体テストを実行する場合:

```shell
python -m unittest discover -v
```

## 設計

ルール、プレイヤー、選択戦略、対戦処理、表示処理を分離しています。

- `rps/model.py`: 手、勝敗、ジャンケンのルール
- `rps/strategies.py`: 手を選択する戦略
- `rps/player.py`: プレイヤーと手ごとの戦績
- `rps/game.py`: 対戦の進行と集計
- `main.py`: コマンドライン入力と結果表示

プレイヤーは名前と`Strategy`を組み合わせて作るため、将来、特定の手だけを返す戦略を追加すれば、既存の対戦処理を変更せずに新しいプレイヤーを追加できます。

## 判定について

ランダム性のテストは再現可能にするため固定シードを使用します。これは乱数生成器そのものの品質を統計的に証明するものではなく、`UniformRandomStrategy`が3手を偏りなく候補に含めていることを、指定された1万回・誤差1%の条件で確認するテストです。

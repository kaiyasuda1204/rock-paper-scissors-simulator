# ジャンケンシミュレーター

のび太とスネ夫がジャンケンを行い、勝率を表示するPythonプログラムです。

## ルール

- のび太（`N`）はグー・チョキ・パーを均等に選ぶ
- スネ夫（`S`）は、自分が過去に出した手のうち勝率が最高の手を選ぶ
- 最高勝率の手が複数ある場合は、その中からランダムに選ぶ
- 未使用の手の勝率は0%とする
- アイコも1回に数えるが、どちらの勝ちにも含めない

## 実行方法

```shell
python main.py 10000
```

出力例:

```text
N: 33.16%
S: 33.52%
```

結果を再現したい場合は乱数シードを指定できます。

```shell
python main.py 10000 --seed 42
```

## テスト

のび太が1万回出した各手の割合が、33.33%から±1ポイント以内か確認します。

```shell
python test.py
```

すべての単体テストを実行する場合:

```shell
python -m unittest discover -v
```

## 構成

- `rps/model.py`: ジャンケンの手と勝敗判定
- `rps/strategies.py`: 手の選択方法
- `rps/player.py`: プレイヤーと戦績
- `rps/game.py`: 対戦と集計
- `main.py`: コマンドライン実行

プレイヤーと手の選択方法を分離しているため、将来は新しい戦略を追加するだけで「グーしか出さないプレイヤー」などを実装できます。
